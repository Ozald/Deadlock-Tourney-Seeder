# Deadlock Tourney Seeder

A lightweight Streamlit web application designed to make balancing teams easier for custom matches in *Deadlock*.

<p align="left">
  <img src="https://cdn2.steamgriddb.com/logo/d1555a36e55c44c60ba4dfb6b4485b82.png" alt="Deadlock Tourney Seeder Logo" width="180"/>
</p>

## Upcoming Features

- **Dynamic Player Count:** Choose roster sizes from 4 to 12 players.
- **Flexible Rank Retrieval:** Support for both manual in-game rank selection and Statlocker profile entry tabs per player.

This is currently a work-in-progress project. Stay tuned!
